# Inventario de Inmuebles — Landing 360°

## Archivos
- `index.html` — estructura
- `styles.css` — diseño responsive
- `script.js` — inmuebles, filtros y navegación al recorrido 360°

## Cómo conectar cada recorrido 360°
En `script.js`, busca cada inmueble y cambia:

tourUrl:"https://example.com/360/chia-villa-placida"

por la URL real que te entregue el proveedor del recorrido 360.

Ejemplo:
tourUrl:"https://mi-tour.com/recorrido/abc123"

Al hacer clic en la foto, nombre, tarjeta o botón **Ver 360°**, se abre ese recorrido en una nueva pestaña.

## Para probar
Abre `index.html` en el navegador.

Los datos de ejemplo son ficticios y las imágenes usan URLs públicas de Unsplash.
