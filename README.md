# felipeinmu
🏠 Inventario Inmobiliario Web — Landing page responsive para visualizar y gestionar un inventario de casas y apartamentos. Incluye filtros por ciudad, localidad, tipo de inmueble, precio y habitaciones, información detallada de cada propiedad, NID identificador, botón para copiar el NID y acceso directo a recorridos virtuales 360°.
